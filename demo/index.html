      A demo you can use

      These initial posts and authors are fictional. This demo uses the extension’s real local keyword scorer, so it is useful to try the flow, but it is not a judgment of a post’s truth or quality.

      Try the threshold, open Capture history, save a post, paste your own text, or import a saved-post snapshot. Reloading keeps your demo on this browser. Reset removes it.

      This page does not connect to X, Ideaflow ID or a live Noos database. The production fork uses those services; this preview lets you try the reader now.
