# Privacy Policy for XFeed Paradise

**Last Updated:** October 26, 2026 (v1.4.0)

## Overview

XFeed Paradise is a browser extension that filters your social media feeds to surface uplifting content and hide negative or outrage-bait posts. We are committed to protecting your privacy.

## Data Collection

### Browser Storage
- Filter settings, your chosen AI provider and model, and any API keys you provide are saved in Chrome `storage.sync`, which may sync across devices signed in to the same Chrome account. Connection status is saved in local extension storage. Keys are never written to logs or status messages.
- A random install ID (a UUID generated by the extension) is saved in local extension storage. It is used only to count the built-in provider's daily limit and is not linked to your name, email or any account.
- Cached tweet/post data is saved locally in IndexedDB.

### Data Sent to External Services

#### Built-in AI provider (default)
New installations, and existing installations without an API key, use the **Built-in (free, daily limit)** provider while AI scoring is enabled:
- Tweet/post or news-item text (up to 400 characters per item) and the random install ID are sent to the XFeed Paradise scoring server, which we operate on Google Cloud Run. The server forwards the text to OpenAI or TypeSafe for scoring and returns only a score.
- The scoring server does not store or log post text. It keeps in-memory counters per install ID and per IP address to enforce the daily limit; these reset daily and are not written to disk. Its request logs record only counts, timing and error codes, not post text, install IDs or IP addresses.
- OpenAI and TypeSafe process the text under their own policies ([OpenAI](https://openai.com/policies/privacy-policy/), [TypeSafe](https://typesafe.ai)).
- To stop using it, switch to another provider with your own key, or turn off AI-powered scoring to use local keyword scoring only.

#### AI provider you choose (Optional)
Nothing is sent to a provider you choose unless you add a key (or, for a custom endpoint, a base URL). If you enable AI-powered scoring:
- Tweet/post or news-item text is sent to the provider you select for sentiment scoring. This text may itself contain personal information.
- If you configure a fallback provider, the same text is sent to it only when the main provider fails, is rate-limited or returns an unusable score.
- The extension uses the API key you provide; it does not include a shared key. Each provider receives only its own key. The built-in provider can also be chosen as the fallback.
- Supported providers and their privacy policies: [Groq](https://groq.com/privacy-policy/), [OpenAI](https://openai.com/policies/privacy-policy/), [Anthropic](https://www.anthropic.com/legal/privacy), [Google Gemini API](https://ai.google.dev/gemini-api/terms), [OpenRouter](https://openrouter.ai/privacy), [Together AI](https://www.together.ai/privacy), [TypeSafe](https://typesafe.ai). A custom endpoint (for example, a local Ollama server) receives the text at the URL you enter.
- For providers other than Groq, Chrome asks for your permission before the extension can contact that provider's host.

The extension does not upload viewed feed items to a community database. A previous version had a community-sync setting; this release no longer uses it, including for existing installations where that setting was enabled.

### Data We Do NOT Collect
- Your name, email, or any personal identifiers
- Your browsing history outside of X/Twitter and Google News
- Your Twitter/X account credentials
- New feed data while filtering is disabled

## Data Storage

- Browser data is stored using Chrome's `storage.sync` and IndexedDB APIs as described above
- We do not sell your data. Your selected AI provider (and fallback, if configured) receives the scoring text described above only when AI scoring is enabled.

## Your Rights

You can:
- Disable the extension at any time
- Clear all stored data via Settings > "Clear stored data"
- Turn off "Use AI-powered scoring" in the popup to use keyword-only scoring, with nothing sent to any server

## Third-Party Services

This extension uses:
- The XFeed Paradise scoring server (built-in provider), which uses OpenAI or TypeSafe, as described above.
- The AI provider you select with your own key (and an optional fallback) for sentiment analysis, as listed above.
