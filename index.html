A calmer X feed, without leaving X.

XFeed Paradise is a free, open-source Chrome extension. It scores each post on X/Twitter and Google News from −100 (outrage-bait) to +100 (uplifting, thoughtful), then hides, dims, or collapses the ones below your threshold.

Download for Chrome · v1.3.2 Install steps (2 min)
Desktop Chrome, Brave, Edge, Arc and other Chromium browsers · 70 KB · No account needed
On your phone? Extensions install on a computer. Open this page on your laptop to set it up.

What it does

Filters the feed you already use

Works directly on x.com, twitter.com and Google News.

You set the threshold

Hide, dim (hover to reveal), or collapse with a “Show anyway” button.

Works out of the box

Keyword scoring runs locally with no setup. Add a free Groq key for smarter AI scoring.

Your feed stays yours

No account, no community upload. Seen posts stay in your browser.

Install

Why the manual steps? XFeed Paradise isn’t in the Chrome Web Store yet, so Chrome needs you to load it yourself once. This takes about two minutes.

  1. Download and unzip

    Download xfeed-paradise-v1.3.2.zip, then double-click it to unzip. Move the unzipped folder somewhere permanent, like Documents. Chrome loads it from that folder, so don’t delete it.

  2. Open the extensions page

    Paste chrome://extensions into the address bar and press Enter. Chrome blocks direct links to this page, so you need to paste it.

  3. Turn on Developer mode

    Use the toggle in the top-right corner of that page.

  4. Click “Load unpacked” and choose the folder

    Select the unzipped folder (the one that contains manifest.json). XFeed Paradise appears in your list. Pin it from the puzzle-piece menu for easy access.

  5. Open X

    Go to x.com and scroll. Low-vibe posts start disappearing right away using keyword scoring.

Optional: turn on AI scoring

Keyword scoring catches obvious outrage. For better judgment on subtle posts, give the extension a free Groq API key. It uses the GPT-OSS 20B model.

  1. Get a free key

    Sign in at console.groq.com/keys and click “Create API Key.” It starts with gsk_.

  2. Paste it into the extension

    Click the XFeed Paradise icon, open Settings & Stats, and paste it into Groq API Key.

  3. Click “Test connection”

    A green status means AI scoring is live. If Groq is down or rate-limited, the extension falls back to keyword scoring and tells you.

FAQ

What data leaves my computer?

Without a Groq key: nothing. With a Groq key, the text of posts being scored is sent to Groq for scoring. Your settings and key are stored in Chrome sync storage, and posts you’ve seen are cached locally in your browser. There’s no community upload. Privacy policy.

Does it work on my phone or in the X app?

Not yet. It’s for desktop Chromium browsers. Chrome on Android and iOS doesn’t support extensions, and no browser extension can filter the native X app.

How do I update?

Download the new ZIP from this page and unzip it over your existing folder. Then click the reload icon on XFeed Paradise’s card in chrome://extensions. Your settings are kept.

Chrome shows a “developer mode extensions” warning

That’s normal for extensions loaded outside the Web Store. You can dismiss it. The full source is on GitHub if you want to check what it does.

How do I pause or remove it?

Toggle filtering off in the popup, or click Remove on its card in chrome://extensions.
